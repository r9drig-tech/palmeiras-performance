# Posições dos visuais (Power BI)

Todas as medidas em **pixels do Power BI** para uma página de **1280 x 720** (Exibir > Configurações da página > Tamanho: *Personalizado* 1280 x 720). Para posicionar: selecione o visual > Formato > Geral > Propriedades > Tamanho e posição (`X`, `Y`, `Largura`, `Altura`).

Imagem de fundo: Formato da página > Tela de fundo > Imagem > *Ajustar*, transparência **0%**.
Os gráficos devem ter **fundo desligado** (o tema já faz isso).

## Dica de produtividade

Monte a **página 1** inteira, depois use *Duplicar página*, troque o fundo e reaproveite as segmentações sincronizadas (Exibir > Sincronizar segmentações). Os botões de navegação e a segmentação de competição podem ser copiados e colados entre as páginas (mesma posição).
